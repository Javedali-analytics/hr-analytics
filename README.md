# HR Analytics — Employee Attrition Analysis

End-to-end HR analytics project analyzing employee attrition using Excel, Python, SQL and Power BI.

## Project Overview

This project analyzes employee attrition patterns to identify workforce segments with higher observed attrition and provide data-driven retention insights.

## Dataset

- Employees: 1,470
- Columns: 35
- Target Variable: Attrition
- Missing Values: 0
- Duplicate Rows: 0

## Tools & Technologies

- Excel — Data preparation and analysis
- Python — Exploratory Data Analysis
- SQL — Business and workforce analysis
- Power BI — Interactive dashboard and visualization

## Key Findings

- Overall observed attrition rate: 16.12%
- Overtime employees show higher observed attrition than non-overtime employees.
- Sales Representatives have the highest observed attrition among job roles.
- Employees under 25 show higher observed attrition.
- Employees with 0–1 years at the company show higher observed attrition.
- Frequent business travelers show higher observed attrition.
- Lower satisfaction levels are associated with higher observed attrition in several satisfaction measures.

## Business Recommendations

- Review overtime and workload patterns.
- Focus retention monitoring on high-attrition job roles.
- Strengthen onboarding and early-career support.
- Monitor frequent-travel employees and workload.
- Review compensation and career progression opportunities.
- Improve employee feedback, engagement and workplace support.
- Monitor work-life balance and employee satisfaction.

## Dashboard

The Power BI dashboard provides an interactive view of employee attrition across departments, job roles, overtime, age, tenure, business travel, income and satisfaction levels.
